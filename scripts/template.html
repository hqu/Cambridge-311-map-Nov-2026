How this was built using Claude Code

Every prompt used to build this map, in order, with a short note on what Claude did after each one.

Get the data first Download the open-tickets file from the City of Cambridge Open Data Portal: Commonwealth Connect Service Requests – Open Tickets. On that page choose Export, then CSV. Save it in your project folder, then attach it to your first prompt in Claude Code by typing @ and the file name. The portal always serves the current open tickets, so your copy will differ from the 9 Nov 2026 snapshot used here.
1

Prompt@Commonwealth_Connect_Service_Requests_-_Open_Tickets_20261109.csv What is in this data?

Claude profiled the file: 1,127 open tickets in 13 columns (ID, issue type, description, three timestamps, address, coordinates, photo link). It listed the most common issue types, the date range (2009 to 2026), and quirks such as mixed date formats and reopened tickets.

2

PromptBuild a map for all the tickets and add a filter by date

Claude downloaded Cambridge's street centerlines and neighborhood boundaries from the city's public GIS repository, grouped the 146 issue types into seven categories, and built this page: a zoomable map, date presets, start and end dates, a monthly bar chart you can drag across, and category toggles.

3

PromptWhen user mouse over a point in the map, the pop up show show a photo if there is one.

Claude downloaded the 753 ticket photos from SeeClickFix, shrank them to small thumbnails (741 were still available), stored them with the page, and added them to the hover popup and the side panel.

4

Promptexport this to my github and name the repo Cambridge 311 map Nov 2026

Claude asked whether the repo should be private or public (the answer was public), then created the repo Cambridge-311-map-Nov-2026 with the map, photos, source data, build scripts and a README, and pushed it.

5

PromptYes, enable Pages

Claude turned on GitHub Pages for the repo, waited for the site to build, checked that the page and photos load, and added the live link to the README.

6

PromptI want to let the user see the entire transcript of the prompts I used to build this artifact. Can you add a link "How this was build using Claude Code". It pop ups a page with the transcript. Include the link https://data.cambridgema.gov/Public-Works/Commonwealth-Connect-Service-Requests-Open-Tickets/bstz-ic97/about_data in the transcript instructions. so users can download the data file.

Claude added the link at the top of the page and this popup, including the instructions for downloading the data.

The prompts are shown as typed, apart from step 1, where the path to the file on the author's computer was replaced with the file name. One prompt sent to this session by mistake, about a different project, is left out.
